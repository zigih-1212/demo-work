# Q2.3 — Mold Tools for Two-Dimensional Ellipses

## Overview

Our 2D ellipse detector is designed with analogically and algorithmically motivated features, including matured insights for patient data processing:
- **Procedural generation** via Cartwright's algebraic geometry, **analytic** and **non-analytic** geometry definitions as validated references.
- **Conic equation** and **parametric yields** for ellipses to support automated processing.
- **Multiple parameterizations** to mirror distinct elliptical representation needs.
- **Invariant definitions** that are algebraic and functional, and algorithmically advantageous.
- **Coordinate-agnostic** format: point sets (x, y) to pair with backend DB storage.

The detection and measurement system is separable, analytically grounded in algebra for implementing a **uniform representation** and **stable coloring**.

## Functions

### 1. Procedural Generation

#### Parametric Form
```javascript
function parametric(t) {
    const x = 16 * Math.pow(Math.sin(t), 3)       // x(t)
    const y = 13 * Math.cos(t) - 5 * Math.cos(2*t) - 2 * Math.cos(3*t) - Math.cos(4*t)  // y(t)
    return [x, y]
}
```
- Domain: $t \in [0, 2\pi)$
- Range: $x \in [-16, 16]$, $y \in [-17, 17]$
- Type: Analytic
- Group: Parametric (non-analytic in scalar form)

#### Analytic Form
```javascript
function analytic(a, b) {
    const dist = Math.sqrt((x/a)**2 + (y/b)**2) // squaring both sides
    return Math.round(dist) === 1
}
```
- Variables: $a, b$ (semi-axes lengths)
- Type: Non-analytic
- Group: Analytic (relationship is analytic)

#### Tensor Form
```javascript
function tensor(a, b) {
    const p0 = [x/a, y/b]
    const p1 = [-x/a, -y/b]
    const p2 = [y/b, x/a]
    const p3 = [-y/b, -x/a]
    return [p0, p1, p2, p3]
}
```
- Variables: $a, b$ (semi-axes lengths)
- Type: Non-analytic
- Group: Tensor (non-analytic)
- Provides bilinear extension

**Note**: The analytic function definition above suffers from complex cancellation issues; this is the intended representation for algorithmic design, not for direct empirical validation.

### 2. Conic and Invariant Definitions

#### Conic Equation (Analytic)
```javascript
function conic(a, b) {
    const c = 1
    const d = 0
    const e = 0
    const f = -1
    const g = -1
    return c * x**2 + d * x + e * y**2 + f * y + g === 0
}
```
- Variables: $a, b$ are derived from $c, d, e, f, g$
- Type: Analytic
- Group: Conic
- Gives $a = 1$, $b = 1$

#### Measuring Proportions (Non-analytic)
```javascript
function measuring_proportions(a, b) {
    const ratio = a / b
    const average = (a + b) / 2
    const max_width = 2 * Math.max(a, b)
    const min_width = 2 * Math.min(a, b)
    return [ratio, average, max_width, min_width]
}
```
- Variables: $a, b$ (semi-axes lengths)
- Type: Non-analytic
- Group: Measuring
- Operator: Division ($1$)

### 3. Coordinate-Agnostic Representation

The detector is coordinate-agnostic, outputting point sets that can be stored directly in the backend database:
```javascript
function coordinate_agnostic() {
    const points = []
    const t_vals = Array.from({length: 50}, (_, i) => i * 2 * Math.PI / 50)
    for (const t of t_vals) {
        const [x, y] = parametric(t)
        points.push([x, y])
    }
    return points
}
```
- Output: `[ [x₁,y₁], [x₂,y₂], ..., [x₅₀,y₅₀] ]`
- Type: Non-analytic
- Group: Coordinate-agnostic
- Format: Point set (x, y) compatible with backend DB storage
